# Page / Section / Field / Type / Validation inventory

อัปเดตเมนู **ประกาศหานักรีวิว** และหน้าภายในจาก routes และโค้ดใน `src/` วันที่ 8 ตุลาคม 2026 (Asia/Bangkok)

ขอบเขตการตรวจรอบนี้: Brief List, Brief Create/Edit modal, Brief Detail, Announcement Create/Edit modal และ Job Posting Detail/รายชื่อนักรีวิว ส่วน Project และ Campaign คง inventory จากวันที่ 7 ตุลาคม 2026 และยังไม่ได้ตรวจซ้ำในรอบนี้

เอกสารนี้บันทึก **พฤติกรรมของ prototype ปัจจุบัน** ไม่ใช่การกำหนด requirement ใหม่ ครอบคลุมหน้าที่มี route, sections, ช่องกรอก, ตัวกรอง, ข้อมูลแสดงผล และ modal ที่เข้าถึงได้จากหน้าเหล่านั้น Create/Edit ที่ใช้ฟอร์มเดียวกันแสดงรวมเพื่อไม่ทำซ้ำทุกแถว

- **บังคับ** = โค้ดตรวจจริงก่อนบันทึก/ไปต่อ
- **UI \*** = มีเครื่องหมายบังคับ แต่ยังไม่มี validation ที่บังคับจริง
- **ไม่ตรวจ** = ไม่พบ validation ใน handler ปัจจุบัน
- **แสดงผล** = read-only ไม่ใช่ช่องรับข้อมูล
- `min`, `type=url`, `accept` เป็นข้อกำหนดที่ input; หากไม่ได้ใช้ native form submit หรือ `checkValidity()` ไม่ถือว่า handler บังคับเงื่อนไขนั้น
- ชื่อในวงเล็บ backtick เป็น property ที่เก็บจริงหรือ state ที่ใช้ใน UI; บางช่อง number เก็บเป็น string จึงแยก UI type จากชนิดข้อมูลที่บันทึก
